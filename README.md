## 📖 Overview

This project is a fundamental web application designed to function as a digital scoreboard. It provides a straightforward interface for tracking scores between two teams, "Home" and "Guest", offering quick adjustments and a reset functionality. Developed as part of the Scrimba Full-Stack Roadmap, it serves as an excellent example of basic client-side web development using vanilla HTML, CSS, and JavaScript. The application focuses on interactive DOM manipulation and event handling to deliver a dynamic user experience without relying on complex frameworks or backend services.

## ✨ Features

-   🎯 **Two-Team Score Tracking**: Dedicated sections for "Home" and "Guest" team scores.
-   ➕ **Incremental Scoring**: Easily add 1, 2, or 3 points to either team with dedicated buttons.
-   🔄 **Score Reset**: A button to instantly reset both team scores to zero.
-   🎨 **Responsive Design**: Designed to be viewable and functional across various screen sizes (inferred from common Scrimba projects and general web best practices, though not explicitly verified from the limited code context).

## 🚀 Quick Start

This project is a static web application and does not require a build process or a specific development server. You can run it directly in your web browser.

### Prerequisites
- A modern web browser (e.g., Chrome, Firefox, Edge, Safari)

### Installation

1.  **Clone the repository**
    ```bash
    git clone https://github.com/DonLuisMunoz/DigitalScoreboard.git
    cd DigitalScoreboard
    ```

2.  **Open in your browser**
    Navigate to the cloned directory and open `index.html` directly in your web browser.
    ```bash
    # Example using a command-line opener (varies by OS)
    open index.html # macOS
    start index.html # Windows
    xdg-open index.html # Linux
    ```
    Alternatively, you can drag and drop the `index.html` file into your browser.

## 🔧 Development

Since this project is a vanilla JavaScript application, development primarily involves editing the `index.html`, `index.css`, and `index.js` files. Any changes made will be reflected by simply refreshing the `index.html` page in your browser.
